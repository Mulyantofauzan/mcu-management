## Temuan, urut prioritas

### P0 — Bisa membuat data hilang / salah
**P0-1 [TERBUKTI] Diam-diam jatuh ke IndexedDB lokal di produksi.**
`js/services/databaseAdapter.js:16-34` memilih Supabase hanya jika `isSupabaseEnabled()`. `js/config/supabase.js` menunggu library maksimal 5 detik lalu menelan semua error. Jika `/api/config` gagal sebentar atau script lambat, semua operasi (tambah karyawan, simpan MCU) tulis ke IndexedDB di browser itu saja. User melihat "berhasil", data tidak ada di server dan tidak terlihat user lain.
Perbaikan: di produksi, jika Supabase tidak siap, tampilkan error blokir dan jangan fallback. Fallback hanya untuk `localhost`.

**P0-2 [TERBUKTI] Token kedaluwarsa tidak ditangani.**
JWT berlaku 8 jam, tanpa refresh. Klien Supabase dibuat sekali dengan token lama (`config/supabase.js getSupabaseOptions`). Tidak ada penanganan `JWT expired` / `PGRST301` di seluruh `js/`. Akibat: setelah 8 jam, tombol gagal dengan pesan tidak jelas, atau halaman kosong.
Perbaikan: pembungkus error global; jika 401/JWT expired, tampilkan "Sesi habis" dan arahkan ke login.

### P1 — Akses / keamanan
**P1-1 [TERBUKTI] Dokter tidak diblok di halaman non-Dokter.**
Hanya `dashboard.js` yang mengarahkan Dokter. `kelola-karyawan.js:322`, `data-master.js:195`, `data-terhapus`, `assessment-rahma` hanya cek login. RLS (`migrations/secure-rls-authenticated.sql`) mengizinkan semua user terautentikasi pada tabel data. Dokter bisa membuka URL langsung dan membaca/mengubah data.
Perbaikan: guard role per halaman memakai satu helper, dan perketat RLS per role.

**P1-2 [TERBUKTI] Hash password lemah.** `server/auth-utils.js`: SHA-256 satu putaran + salt. Format lama (base64 password) masih diterima. Ganti ke bcrypt (`bcryptjs` sudah terpasang), migrasi saat login.

**P1-3 [TERBUKTI] Tidak ada rate limit login**, dan pesan beda untuk "user tidak ada" vs "password salah" (`api/login/index.js`). Satukan pesan, tambah pembatasan percobaan.

**P1-4 [TERBUKTI] Pembuatan/ubah user hash di browser** (`authService.createUser`, `updateUser`) lalu tulis langsung ke tabel `users`. Pindahkan ke endpoint server.
