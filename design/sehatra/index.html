Template UI Sehatra

Empat belas halaman statis untuk aplikasi Manajemen MCU. Dipakai sebagai acuan visual sebelum rebuild.

Semua nama dan angka adalah data contoh

Cara membaca template. Buka satu halaman, lalu coba: tombol bulan atau matahari untuk tema terang dan gelap; tombol Normal, Memuat, Kosong, Galat untuk kondisi data; klik baris atau tombol Detail untuk dialog; tekan Esc untuk menutup. Komentar di bagian atas tiap file HTML memuat sumber halaman asli dan daftar paritasnya.
